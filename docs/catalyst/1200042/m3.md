## Real-world application evidence

### Token Launch

Token Launch uses `@blaze-cardano/deploy` to describe its three Mainnet reference scripts as a deployment manifest and reconcile them against live Blockfrost state. Running `bun run verify:deployments` checks that each result is `reuse` and that the returned UTxO matches the reference committed by the application. The [integration commit](https://github.com/butaneprotocol/token-launch/commit/42bf48ad566181c000f97ccc9fb6485b46520977) and [verification command](https://github.com/butaneprotocol/token-launch/blob/main/scripts/verifyDeployments.ts) are public.

The live verification completed successfully with manifest hash `ee1a145c9050b556decc128d9bdbac1761c29477de074ed5e2c4b0bd90389f4b`. It found the `claiming`, `vesting`, and `btn` scripts at their recorded reference UTxOs and finished with `Verified 3 reference scripts.` The verified transactions are visible on Cardano Mainnet: [`351c70a5...e12d0329`](https://cardanoscan.io/transaction/351c70a54045232dcca9719c0c0d55f33fcfaf8094dcd8d461aa3723e12d0329) and [`5014bfeb...d97599d5`](https://cardanoscan.io/transaction/5014bfeb7119e7e18fa00d3f37f40ddfe337131b77fd1408ca6e21f1d97599d5).

### Butane Protocol

Butane's deployment CLI uses `@blaze-cardano/deploy` to reconcile the protocol's committed Mainnet v1 deployment artifact against the live chain. The application repository is private, so this case study records the exact command and the complete result without exposing source code or credentials.

```sh
pnpm --filter @butaneprotocol/deploy butane --mainnet verify-deployments --deployment deployments/v1.deployment.json
```

This command is read-only. It builds a manifest from the full script-reference UTxOs stored by Butane, queries the live deployment addresses through Blockfrost, and fails unless every planned action is `reuse` at the transaction input recorded by the application. It does not load a wallet, sign a transaction, or submit anything to the network.
